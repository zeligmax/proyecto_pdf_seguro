#Notes:

#cryptography: Used for PDF encryption/decryption with Fernet (AES-based).

#requests: Used to fetch public IP and send logs to the server.

#flask: Needed if you want to run the included remote server (server/server.py) and Users API.

#flask-cors: Enables CORS (Cross-Origin Resource Sharing) for the Users API.

#PyMuPDF: Used for the in-memory PDF viewer to render PDF pages as images. Enables viewing PDFs without saving to disk (v2.1 feature).

#Pillow: Image processing library used with PyMuPDF to display rendered PDF pages in the GUI viewer.

#pywin32: Windows-specific library for WMI access (better user detection on Windows).

#tkinter: Used for the GUI. It comes pre-installed with most Python distributions, but added for completeness (platform-specific).

#pyinstaller: Optional. Used only if you want to compile the GUI into a .exe or .app.

#How to use it:

#With your virtual environment activated:

#pip install -r requirements.txt

#Optional installations:

#For minimal installation (only encryption/decryption without PDF viewer):
#pip install cryptography

#For full installation with in-memory PDF viewer (recommended):
#pip install cryptography PyMuPDF Pillow

#Note: PyMuPDF and Pillow are optional. If not installed, the "View PDF" button will show a message
#explaining how to install them, but you can still use "Decrypt and Save" to decrypt PDFs normally.
